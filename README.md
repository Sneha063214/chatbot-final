
✈️ Flight Chatbot System

A simple and interactive Flight Chatbot built using Python (Flask), HTML, and CSV data.

This chatbot helps users get information about flights such as delays, timings, and basic queries.

🚀 Features
💬 Chat-based interaction

📊 Uses real flight dataset (flights.csv)

⏱️ Provides delay and timing information

🌐 Simple web interface using HTML

⚡ Fast response using Flask backend


🛠️ Tech Stack
Python

Flask

Pandas

HTML / CSS

CSV Dataset
